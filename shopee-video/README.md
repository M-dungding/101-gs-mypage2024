# เครื่องมือสร้างคลิป Shopee Video

สร้างคลิปแนวตั้ง 9:16 (1080×1920) จากรูปสินค้า 3–5 รูป เอาไปลง Shopee Video แล้วปักตะกร้าได้เลย
และเอาไปลง TikTok ต่อได้ เพราะคลิปไม่มีลายน้ำ

ในคลิปจะมี:
- ข้อความ Hook บนสไลด์แรก
- ข้อความจุดเด่นบนสไลด์ถัดไป
- ป้ายราคา และปุ่ม "กดตะกร้า" ที่สไลด์สุดท้าย
- ข้อความแจ้งว่าเป็นลิงก์ affiliate
- ภาพซูมเข้าช้าๆ ให้ดูมีการเคลื่อนไหว

ด้านล่างและด้านขวาของคลิปจะเว้นว่างไว้ เพราะเป็นตำแหน่งที่ปุ่มตะกร้าและปุ่มไลก์ของแอปจะทับ

## ต้องมี

- Python 3 และ Pillow (`pip install pillow`)
- ffmpeg (Mac: `brew install ffmpeg`, Windows: `winget install ffmpeg`)

## วิธีใช้

1. บันทึกรูปสินค้าจากหน้าร้าน Shopee (หรือถ่ายเอง) ไว้ในโฟลเดอร์ `images/`
2. คัดลอก `clip.example.json` เป็นไฟล์ใหม่ แล้วแก้ข้อความ ราคา และชื่อรูป
3. รันคำสั่ง:

   ```
   python3 make_clip.py clip_ของฉัน.json
   ```

4. จะได้ไฟล์ `.mp4` และรูปปก `_cover.jpg` อยู่ในโฟลเดอร์เดียวกับไฟล์ตั้งค่า

ช่อง `image` ใส่ลิงก์รูปได้เลย (เช่น `https://down-th.img.susercontent.com/file/...`) เครื่องมือจะดาวน์โหลดให้เอง
ถ้ามีแค่ลิงก์ affiliate ให้ลอง `python3 make_clip.py --from-link ลิงก์` เพื่อหาลิงก์รูปหลักของสินค้า
(Shopee อาจบล็อกการดึงหน้าเว็บ ถ้าไม่เจอให้คัดลอกที่อยู่รูปจากหน้าเว็บ Shopee เอง)

ถ้าอยากดูตัวอย่างก่อน ใช้คำสั่ง `python3 make_clip.py --demo demo` จะได้คลิปตัวอย่างจากรูปจำลองในโฟลเดอร์ `demo/`

## ค่าที่ตั้งได้ในไฟล์ .json

| ค่า | ความหมาย |
| --- | --- |
| `output` | ชื่อไฟล์คลิปที่จะได้ |
| `hook` | ข้อความเปิดบนสไลด์แรก ใช้ `\n` เพื่อขึ้นบรรทัดใหม่ |
| `price` | ป้ายราคา แสดงบนสไลด์แรกและสไลด์สุดท้าย |
| `cta` | ปุ่มชวนกดซื้อ แสดงบนสไลด์สุดท้าย |
| `disclosure` | ข้อความแจ้งว่าเป็นลิงก์ affiliate แสดงทุกสไลด์ |
| `music` | ไฟล์เพลง .mp3 (ไม่ใส่ก็ได้ ถ้าไม่ใส่จะได้คลิปไม่มีเสียง แล้วไปเลือกเพลงในแอปแทน) |
| `font` | ฟอนต์ไทย .ttf/.otf ที่อยากใช้ (ไม่ใส่ก็ได้) |
| `slides` | รายการรูป: `image` = ไฟล์รูป, `text` = ข้อความบนรูป, `seconds` = ยาวกี่วินาที |

ข้อความภาษาไทยจะตัดบรรทัดตามช่องว่าง ถ้าอยากกำหนดจุดขึ้นบรรทัดเองให้ใส่ `\n`

## ลงคลิปและปักตะกร้า

1. เปิดแอป Shopee ไปที่ "ฉัน" แล้วเข้า Shopee Video กด "+" (หรือ "สร้างวิดีโอ")
2. เลือกคลิปที่สร้างไว้ และเลือกเพลงในแอปถ้าคลิปยังไม่มีเพลง
3. กด "เพิ่มสินค้า" แล้วเลือกสินค้าตัวเดียวกับในคลิปจากรายการ Affiliate
4. ใส่แคปชั่นและแฮชแท็ก (ดูตัวอย่างในคู่มือ) แล้วกดโพสต์

ชื่อเมนูอาจต่างไปตามเวอร์ชันแอป
