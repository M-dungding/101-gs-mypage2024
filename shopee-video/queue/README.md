# คิวรูปสินค้า

อัปโหลดรูปสินค้าไว้ที่โฟลเดอร์นี้ แล้ว loop ทำคลิปจะหยิบไปใช้เอง

## วิธีอัปโหลด

1. ในเว็บ Shopee บนคอม เปิดหน้าสินค้า คลิกขวาที่รูป แล้วเลือก "บันทึกรูปภาพ" ประมาณ 3–5 รูป
2. ตั้งชื่อไฟล์ให้ขึ้นต้นด้วยรหัสสินค้าในตารางคิว ตามด้วยขีดกลางและลำดับ เช่น
   `P001-1.jpg`, `P001-2.jpg`, `P001-3.jpg`
3. ในหน้านี้บน GitHub กด **Add file → Upload files** แล้วลากรูปทั้งหมดมาวาง
4. กด **Commit changes**

รูปจะถูกใช้ตามลำดับชื่อไฟล์ รูปแรก (`-1`) จะเป็นรูปปกและสไลด์แรก
ใช้ได้ทั้ง .jpg .png และ .webp
